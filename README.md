# DES Control Center

Настольная панель для Windows на WPF и .NET 8. Показывает состояние Linux-серверов,
сайтов, systemd-служб, Docker-контейнеров и VPN. Позволяет читать логи,
управлять службами и получать уведомления в Telegram.

Публичный репозиторий называется `DES-control-center-public`. Все названия узлов,
приложений и адреса в демонстрационных данных вымышлены.

[Описание и скриншоты DES Control Center](https://котификация.рф/projects/des-control-center).

## Возможности

- Карточки серверов с CPU, RAM, диском, uptime и сетевой статистикой.
- Проверки HTTP и сроков TLS-сертификатов.
- Опрос systemd-служб и Docker-контейнеров, запуск, остановка, перезапуск и просмотр логов.
- Проверка VPN-контейнеров, свежести резервных копий и состояния заданий обслуживания.
- Приглушение тревог, журнал событий SQLite, напоминания и сводки в Telegram.
- Настраиваемые переключатели с подтверждением действия.
- Запуск установленных приложений с панели.
- Тёмная и светлая темы, значок в трее, горячая клавиша Ctrl+Alt+C.
- Деморежим с вымышленной инфраструктурой и имитацией проверок.

## Сборка

Нужны Windows 10 версии 19041 или новее, .NET 8 SDK и системный клиент OpenSSH.
Команды выполняются из корня репозитория.

```powershell
dotnet restore DesControlCenter.sln
dotnet build DesControlCenter.sln --no-restore
dotnet test tests/DesControlCenter.Core.Tests --no-build --no-restore
```

Исполняемый файл Debug-сборки находится в
`src/DesControlCenter.App/bin/Debug/net8.0-windows10.0.19041.0/DesControlCenter.App.exe`.
Перед повторной сборкой завершите запущенное приложение через пункт «Выход» в меню трея.

## Демонстрация

```powershell
$env:DES_DEMO = '1'
try {
    & './src/DesControlCenter.App/bin/Debug/net8.0-windows10.0.19041.0/DesControlCenter.App.exe'
} finally {
    Remove-Item Env:DES_DEMO -ErrorAction SilentlyContinue
}
```

Деморежим использует имитацию серверов, сайтов и команд. Его данные хранятся отдельно
в `%TEMP%/DesControlCenterDemo`. Заголовок окна помечен словом «демо».

## Подключение своей инфраструктуры

Для обычного запуска выполните приложение без `DES_DEMO`. Добавьте свои ресурсы через
«Настройки». Файлы приложения находятся в `%AppData%/DesControlCenter`.

- `app-settings.json` содержит конфигурацию ресурсов.
- `events.db` содержит журнал событий.
- `silences.json` содержит приглушения.
- `reminders.json` содержит напоминания.
- `ui-settings.json` содержит выбранную тему.

Примеры конфигурации находятся в [examples/app-settings.example.json](examples/app-settings.example.json)
и [examples/ssh-config.example](examples/ssh-config.example). Замените демонстрационные значения
своими перед использованием. Связи ресурсов задаются через `Id` и `ServerId`.
`Kind` в JSON имеет значение `0` для systemd и `1` для Docker.

SSH-подключения выполняет системный OpenSSH. Можно указать алиас из `~/.ssh/config`
или параметры узла в настройках. Доступ и права для команд настраиваются владельцем сервера.
Команды управления выполняются с теми правами, с которыми входит SSH-пользователь.

Для уведомлений Telegram приложение принимает токен из локального `telegram-token.txt`,
затем сохраняет его с защитой Windows DPAPI и удаляет исходный файл после проверки.
Файл `telegram.json` содержит поле `ChatId`. Храните рабочие настройки, журналы и ключи
вне репозитория.

## Структура

| Каталог | Назначение |
|---|---|
| `src/DesControlCenter.Core` | Модели, интерфейсы, планировщики и агрегация состояния |
| `src/DesControlCenter.Infrastructure` | SSH, мониторы, хранилища, уведомления |
| `src/DesControlCenter.App` | WPF-интерфейс, модели представления, трей и деморежим |
| `tests/DesControlCenter.Core.Tests` | Тесты поведения с подменами внешних сервисов |
| `scripts` | Генерация и просмотр значков трея |
| `examples` | Вымышленные примеры настройки |

## Известное ограничение сборки

Зависимость `H.NotifyIcon.Wpf 2.4.1` вызывает предупреждение NuGet `NU1701`
о выборе сборок для .NET Framework при целевой платформе .NET 8.
Состояние этой зависимости требует отдельной проверки совместимости.
